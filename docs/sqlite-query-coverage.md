# SQLite query coverage

These tests use isolated SQLite databases and check data or query results. `EfDatabaseCompatibilityTests` also checks a database generated by EF at baseline commit `b1694cff743c68db9d60e3dad2baba5817defdb7` against the new schema and opens its existing rows. Coverage of a SQL path does not imply every failure mode is exercised.
